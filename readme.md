# Weather App 🌤️

A simple weather app built with HTML, CSS, and JavaScript.

## Features

- Search weather by city
- Shows current temperature
- Shows humidity
- Shows wind speed
- Dynamic weather icons
- Search using the Enter key
- Handles invalid city names

## Technologies

- HTML
- CSS
- JavaScript
- OpenWeather API

## How it works

The app sends the searched city name to the OpenWeather API using JavaScript `fetch()`, receives the weather data, and updates the page with the current information.
